# 产品需求文档：拾题 Web MVP

## 1. 产品定位

拾题帮助高中数学教师把已有试卷快速整理为学生专属错题文档。

它不是阅卷系统，也不判断学生答案。教师已经知道学生错了哪些题，只需要选择学生和试卷并输入错题号，系统负责查找题目、排序和生成 Word。

## 2. 目标用户

首版用户为单个高中数学教师。

典型场景：

1. 教师上传一份函数单元测试。
2. 系统识别出第 1 至 20 题。
3. 教师在完整试卷上核对题号按钮。
4. 教师选择张三，直接勾选 2、5、8、12。
5. 系统生成张三的函数单元测试错题集。

## 3. MVP 目标

- 建立可修改的学生名单。
- 一份试卷只上传和校正一次，之后可被多个学生重复使用。
- 将“查找、复制、排序、排版错题”的重复劳动压缩为一次表单操作。
- 自动识别错误时可由教师校正，不让自动化结果成为不可修改的黑盒。

## 4. 功能范围

### 4.1 学生管理

- 添加学号、姓名、班级和备注。
- 查看完整学生名单。
- 修改学生信息。
- 没有错题集历史时可以删除学生。
- 学号在当前数据文件内唯一。

### 4.2 试卷文档

- 上传 PDF 或 DOCX，最大 500 MB。
- 试卷名称可手动填写；留空时使用文件名。
- 图片型 DOCX 提取整页原图，只识别主问题号的页面坐标，不识别题干或公式。
- 在完整试卷上显示题号选择按钮，页面缩放时按钮仍与题号对齐。
- 可使用新版规则重新识别已上传试卷；也可删除错误标记、输入题号并在页面题首点击补放标记。
- 依据相邻主问题号切割题目截图，支持一道题跨越两个页面。
- 文本型文档继续提取文字并识别主问题号。
- 显示识别数量、警告和所有试卷页面。
- 修改题号与正文。
- 删除误识别题目。
- 手动添加漏识别题目。

### 4.3 题号识别

文本模式自动支持：

- 1. 题目正文
- 2、题目正文
- 3）题目正文
- 第4题 题目正文

“（1）（2）”形式默认作为大题内部小问，不拆成独立主问题。

图片模式使用中文印刷体 OCR 定位题号，并结合题号格式、候选置信度和空间连续关系验证主问题号。数字限定 OCR 不得单独把 `(i)/(ii)` 等罗马数字小问推断为主问题号。识别结果仅用于坐标，不作为题目正文；题目正文、数学公式、函数图像和几何图全部保留为原始页面像素。

系统按候选可信度和连续顺序选择主问题号；低可信候选不能挤掉后续真实主问题号。识别后教师始终可以在完整页面中人工删除误标、补放漏题并重新计算裁剪边界。

### 4.4 错题集生成

- 选择一个学生。
- 选择一份已上传试卷。
- 在完整试卷题号旁直接勾选一个或多个错题；同时保留手工输入题号的批量入口。
- 题号支持空格、英文/中文逗号、顿号和分号分隔。
- 输入不存在的题号时阻止生成，并返回具体缺失题号。
- 生成内容按试卷题目顺序排列，而不是按教师输入顺序。
- 文档名称自动组合为“试卷名称 · 学生姓名 · 班级 · 学号”，不要求教师额外填写标题。
- 返回 DOCX 下载并保存生成记录。
- 历史记录支持重新生成和下载。

## 5. 明确不做

- 登录、角色、租户和多人协作。
- 题干 OCR、手写公式识别和数学公式语义还原。
- 自动判题、成绩分析和知识点分析。
- 学生端、支付和消息推送。
- 将图片试卷转写为可编辑公式或文字。
- 数学公式语义识别、MathType 转换。
- 云存储、在线备份和公开互联网部署。

## 6. 文档输入规则

- PDF 有文字层时提取文字；扫描型 PDF 没有文字层时自动渲染页面图片并定位题号。
- DOCX 可以包含普通段落文字，或包含清晰的整页 PNG 试卷图片。
- 题号独立出现在行首时识别效果最好。
- 教师必须在首次使用试卷前检查拆题预览。
- 原始上传文件会保存在本地数据目录，便于后续重新处理。

## 7. DOCX 输出规则

- Letter 纵向，四边 1 英寸页边距。
- 显示自动组合的文档名称、学生姓名、学号、班级和来源试卷。
- 每题使用清晰的“第 N 题”标题。
- 图片题直接嵌入按题号边界裁剪的原图；跨页题嵌入多个连续截图。
- 文本题保留提取文本的换行。
- 题目之间使用分隔线。
- 页脚包含产品说明和页码。
- 文档可在 Word 或兼容软件中继续编辑。

## 8. 核心页面

| 页面 | 目的 |
| --- | --- |
| 工作台 | 查看学生、试卷、题目和生成数量，进入三步流程 |
| 学生名单 | 添加和维护学生 |
| 试卷文档 | 上传试卷、查看试卷列表 |
| 原卷选题 / 拆题预览 | 查看完整试卷、在题号旁勾选；文本模式校正题目正文 |
| 生成错题集 | 选择学生、试卷、错题号并下载 Word |

## 9. 验收标准

### 学生

- 添加学生后立即出现在名单中。
- 学号重复时给出中文错误提示。
- 修改后刷新页面仍保留。

### 文档

- 示例 DOCX 的 1.、2、和“第3题”被识别为三道题。
- “（1）（2）”保留在第 3 题正文。
- 示例文本型 PDF 被正确识别为两道题。
- 500 MB 以上或非 PDF/DOCX 文件被拒绝。
- 真实 4 页图片型 DOCX 保留 4 张完整页面，并连续定位第 1 至 19 题。
- 真实 44 页图片型题目合集连续定位第 1 至 44 题，第 4 题位于第 4 页题首，不得把第 3 题的 `(ii)` 识别为第 4 题。
- 每个题号按钮显示在原卷对应题号旁，选择后可直接生成错题集。
- 图片识别结果可重新识别、删除误标并在页面点击补充；文本识别结果可以修改、删除和补充。

### 错题集

- 选择题号 1、3 时，下载的 Word 只包含第 1、3 题。
- 图片型试卷生成的 Word 使用原题截图，复杂公式和图片与原卷一致。
- 跨页题目的所有截图都进入同一道题，不能遗漏下一页内容。
- 文档包含正确学生和试卷信息。
- 输入不存在题号时不创建错误记录。
- 历史记录可重新下载。

## 10. 非功能要求

- 所有外部输入在服务端重新校验。
- 上传文件使用随机内部文件名，不信任原始文件名路径。
- JSON 写入使用临时文件替换，避免写到一半破坏数据库。
- 同一进程中的写操作串行执行。
- 页面支持桌面、平板和手机宽度。
- 关键流程具备单元测试和真实浏览器验收。

## 11. 已知限制与风险

| 风险 | 当前应对 |
| --- | --- |
| 题干 OCR 会破坏数学公式与图形 | 不转写题干；只定位题号并使用原图裁剪 |
| 题号定位遗漏或误判 | 主问题候选分级、连续关系验证、完整原卷预览、重新识别和人工增删标记 |
| PDF 阅读顺序不稳定 | 按页面坐标重组文字行，保留页码标记 |
| 题号风格多样 | 规则测试和人工补充；用真实样本持续扩充 |
| JSON 不适合多人并发 | 明确限定单教师；多人版本迁移 PostgreSQL |
| 无登录时公网暴露会泄露学生数据 | 仅本地或可信内网使用 |

## 12. 下一版本候选

- Excel 批量导入学生。
- 按班级筛选和批量生成多个学生错题集。
- 题号位置拖动与裁剪边界微调（漏题点击补点已完成）。
- 题目标签、知识点和练习答案页。
- 登录、PostgreSQL、对象存储和备份。
